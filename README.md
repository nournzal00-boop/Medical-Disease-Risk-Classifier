# Medical Disease Risk Classifier (AI Model)

## Overview
This project leverages Machine Learning algorithms to analyze medical metrics (such as glucose levels, BMI, and age parameters) to perform binary risk classification and evaluate patient health risks accurately.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn

## How It Works
1. Synthetic scientific health dataset processing.
2. Standardized feature scaling using `StandardScaler`.
3. Binary risk classification using the `LogisticRegression` algorithm.
4. Evaluation and inference pipeline for new patient diagnostic metrics.
